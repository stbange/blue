## Why

The computer keyboard currently plays one chromatic octave. Players need a larger range and a way to play within a chosen scale, including microtonal scales.

## What Changes

Map the 36 letter and number keys to consecutive degrees across repeating octaves. Add a preset dropdown, pitch labels and an editable Custom tuning on desktop and web. Store factory scales as loose data and send fractional MIDI pitches to the shared C engine.

## Capabilities

### New Capabilities

- `keyboard-tuning` covers the full-range computer keyboard, selectable tunings and a cents-based builder.

## Impact

The new note event separates the keyboard key identity from its fractional pitch. Browser and native interfaces use it for keyboard and pointer performance. The desktop reload and record shortcuts move to F11 and F10 to free Z and R for playing.
