## Why

Blue ships four performance sounds and one calibration patch. Players need contrasting sustained textures and shorter articulations they can audition on the same instrument.

## What Changes

Add 24 original presets in four banks of six. Formants explores voices and reeds, Littoral uses original granular source material, Nocturnes uses spectral and spatial motion, and Signals supplies tempo patterns and struck sounds. Ship each bank as editable content with its own performance mapping. Bundle the previously separate Tideline study. Keep existing preset names, order and startup selection.

## Capabilities

### New Capabilities

- `factory-library` covers the expanded catalog, performance controls and packaged audio checks.

## Impact

The change uses the existing v1 pack format, C renderer, Lua API and native, web and WebXR content loaders.
